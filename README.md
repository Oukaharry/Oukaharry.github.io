# Harrison Odhiambo Ouka

Personal site and blog for **Harrison Odhiambo Ouka** (Harry Ouka / Ouka Harry), a software developer in Nairobi, Kenya.

GitHub Pages serves this repository from the `main` branch at [https://oukaharry.github.io](https://oukaharry.github.io). The site is plain HTML, CSS, and a small script. An empty `.nojekyll` file tells GitHub Pages to publish the files as they are.

## Pages

- `/` — home
- `/about/` — bio and the stack that shows up in the public repositories
- `/projects/` — TradeManagerEA, HedgePass Pro, and the ALX coursework repos
- `/blog/` — notes, with an RSS feed at `/feed.xml` and Atom at `/atom.xml`
- `/contact/` — email, GitHub, LinkedIn, DEV, and MQL5 profiles

## Edit and rebuild

Page chrome, projects, and feeds are generated by `scripts/build_site.py`. Post bodies live in `content/posts/`. After editing, run:

```bash
python3 scripts/build_site.py
```

`scripts/make_images.py` redraws the favicon and the Open Graph image. It needs Pillow, which is a local tool, not a dependency of the published site.

## Google Search Console

Verification is not turned on yet. Put the token in [`config/search-console.txt`](config/search-console.txt) (`GOOGLE_SITE_VERIFICATION=`), then rebuild. Until that value replaces `PASTE_TOKEN_HERE`, pages keep an HTML comment in `<head>` showing the meta tag to add. After the site is verified, submit `https://oukaharry.github.io/sitemap.xml`.
